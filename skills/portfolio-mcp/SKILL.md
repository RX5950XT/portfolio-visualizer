# Portfolio Visualizer MCP

MCP 伺服器名稱依用戶端設定（常見為 `portfolio` 或 `portfolio-visualizer`）。所有數字與網站完全相同：計算與寫入都和網站共用同一份程式。

## 開始前

1. 先呼叫 `portfolio_list` 取得組合 `id` 與名稱。使用者沒指定組合時：
   - 讀取類問題：用 `is_default: true` 的組合，並在回答中說明是哪個組合；使用者說「全部」才省略 `portfolio_id`（合併所有真實組合）。
   - 寫入類操作：**一定要明確的組合**；有多個組合且使用者沒說，先問。
2. 工具回 401 或連不上：請使用者到網站 `/settings` 檢查 MCP 金鑰是否被重設或撤銷。

## 工具與用途

| 使用者想知道 | 工具 |
|---|---|
| 總資產、持股、現金、未實現損益、權重、ETF 費用率 | `portfolio_snapshot` |
| 每筆買賣紀錄、已實現損益、已出清的股票、`lotId` | `portfolio_trades` |
| 報酬率、TWR、XIRR、跟大盤比、最大回撤、波動率、Sharpe、勝率 | `portfolio_performance` |
| 資產走勢、和 S&P 500 走勢比較 | `portfolio_asset_trend` |
| 每天賺賠、某段期間每日損益 | `portfolio_daily_pnl`（`days`，或 `start`＋`end`） |
| 配息、殖利率、即將除息 | `portfolio_dividends` |
| 真實重倉（穿透 ETF）、產業／地區分佈、集中度 | `portfolio_lookthrough` |

寫入工具：`holding_add`（新增買入）、`holding_sell`（賣出）、`holding_update`（編輯一筆買入）、`cash_set`（設定現金）。

## 單位（最常出錯，務必遵守）

- 金額一律新台幣（TWD）。`price`、`cost_price`、`costPrice` 是標的原幣：美股 USD、台股 TWD。
- `portfolio_snapshot` 的 `weight`、`gainPercent` 是**百分點**（25 = 25%）。
- 其他工具的報酬、殖利率、回撤、`pct`、`expenseRatio`、`weightedExpenseRatio` 是**小數**（0.12 = 12%，0.0007 = 0.07%）。
- 台股代號加 `.TW`（上市）或 `.TWO`（上櫃）；美股直接寫代號（`VT`、`AAPL`）。
- `valuationComplete: false` 時看 `warnings`：缺報價的標的市值暫記 0，總額不完整，**不可說成虧損**。

## 名詞（回答時用白話）

- **未實現損益**：現有持股的市值減成本，還沒賣。
- **已實現損益**：已賣出部分真正落袋的賺賠（`portfolio_trades.totalRealizedPnlTwd`）。
- **TWR**：排除資金進出時點的策略報酬，用來跟大盤比。**XIRR**：考慮實際投入金額與時間的個人年化報酬。兩者不同屬正常。
- **跟大盤比／同期**：從投組第一筆買入日（含已賣光的批次）到今天，同一段時間 S&P 500 的報酬，以台幣計、含匯率變動。`excess` > 0 表示贏過大盤。
- **最大回撤**：從高點跌下來最深的幅度；`benchmarkTrough` 是同期 S&P 500 的最深回撤。

## 寫入操作守則

寫入會直接改使用者的真實資料，且**新增與賣出沒有防重複機制**。每次都照這個順序：

1. **補齊資訊**：缺組合、代號、股數、價格或日期就問；不要自己猜價格或日期（「今天」可用當天日期，但要在確認時寫出來）。
2. **先讀再寫**：
   - 賣出前用 `portfolio_snapshot` 確認持有該標的與股數，賣出股數不可超過持有量。
   - 編輯前用 `portfolio_trades` 找到正確的 `lotId`（只能編輯仍有剩餘股數的批次）。
   - 設定現金前用 `portfolio_snapshot` 讀目前現金。
3. **一次確認**：用一句話列出將執行的內容並等使用者同意，例如：
   「將在 rx5950xt 賣出 VT 2 股，成交價 USD 160，日期 2026-10-16；賣得金額會加回現金。確定嗎？」
4. **執行一次**：只呼叫一次。若回應逾時或不明，**不要直接重試**；先用 `portfolio_trades`（新增／賣出）或 `portfolio_snapshot`（現金）確認是否已寫入。
5. **回報結果**：用工具回傳值說明，例如賣出後的已實現損益與加回的現金、編輯前後差異、現金修改前後金額。

各寫入工具的行為：

| 工具 | 行為 | 注意 |
|---|---|---|
| `holding_add` | 新增一筆買入批次 | **不扣現金**；使用者若要同時扣現金，另外用 `cash_set`（先確認） |
| `holding_sell` | 該組合中此代號的所有批次依比例扣減；以加權均價計已實現損益（美股成本用買入日匯率、賣價用賣出日匯率）；賣得金額加回現金 | 不能指定只賣某一批 |
| `holding_update` | 覆寫一筆批次的代號／股數／成本價／買入日，只傳要改的欄位 | 改股數**不會**產生賣出紀錄、不動現金；真的賣出要用 `holding_sell` |
| `cash_set` | 把現金**直接設為**新金額 | 不是加減；「現金加 1 萬」要先讀目前金額再算出新值，並在確認時寫出新值 |

## 做不到的事

不能刪除持股或交易紀錄、不能建立或刪除組合、不能改登入或 MCP 設定、不能存取 Demo 沙盒。使用者要求時，請他到網站操作。

## 錯誤處理

- 工具回傳 `isError: true` 且訊息具體（如「賣出股數 (5) 超過持有量 (3)」「找不到投資組合」）：照訊息向使用者說明並請他修正。
- 訊息是通用的「無法讀取或寫入投資組合」：伺服器暫時錯誤，稍後重試**讀取**；寫入先確認狀態再決定是否重做。
- 參數驗證失敗：檢查代號格式、日期 `YYYY-MM-DD`、數字需大於 0、`portfolio_id`／`lot_id` 需為 UUID。

## 隱私

投資資料屬於個人敏感資訊。只在回答使用者問題時引用，不要主動彙整後傳到其他服務或工具。
